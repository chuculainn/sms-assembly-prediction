运行方式：
1. 解压本软件包
2. 打开 Anaconda Prompt 或终端
3. cd 到 sms_streamlit_E1_demo_project 目录
4. pip install -r requirements.txt
5. streamlit run app.py

python scripts/cli_check.py data/E1_min_closed_loop

python scripts/cli_check.py data/01_DEFAULT_MIN_CASE_4_PART
