运行方式：
1. 解压本软件包
2. 打开 Python 3.11 终端
3. cd 到解压后的当前项目根目录（应直接包含 app.py、core、data、tests，不要再创建 sms_streamlit_E1_demo_project 重复目录）
4. python -m pip install -r requirements.txt
5. python -m streamlit run app.py

python scripts/cli_check.py data/E1_min_closed_loop

- 选择 data/01_DEFAULT_MIN_CASE_4_PART
