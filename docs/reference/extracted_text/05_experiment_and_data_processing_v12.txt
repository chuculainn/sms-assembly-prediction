0 总体闭环：先确认这套流程为什么能走通
本模型的可运行核心不是“画一个流程图”，而是把每个物理对象变成可计算的数据对象，并保证每个对象只
有一个明确来源、参考态和消费位置。整体上，它要解决三件事：装配前形貌如何进入初始间隙；阶段边界和
接触如何改变结构状态；局部界面响应如何传递为最终 KCP。
I = {I0, IΓ, Istage, Ikey, Imeas, Ired, Ipred, Istat}

F_fast : ξ -> [g0 -> {S^(s)}_{s=1..4} -> {Δγ_c^(s)} -> Δy_KCP]

ξ = [α_SMS, e_proc, θ_interface, ε_model]^T

最小可走通条件如下。
条件                                  必须具备的数据或算子                    若缺失会卡在哪里
几何与形貌                               名义模型 X0、SMS 基 N、KCM 或虚拟 SMS   无法得到 δ_SMS 和 g0
接触域                                 候选点 Ω、法向 n、面积权重 QA、G、Bn       无法把间隙和接触力写成 LCP
结构响应                                阶段 W_struct 或 KΓ 缓存           每个样本都必须回全阶有限元
界面参数                                Cn/Ct/μ/βr 或其先验               局部压缩、滑移、回弹无法进入 KCP
                                    定位、夹持、连接、释放的边界/载荷/锁定
阶段工艺                                                              无法形成路径依赖和释放回弹
                                    规则
预测映射                                JSS/J-T、KCP 定义、贡献台账           无法把接触状态变成质量指标
验证与统计                               D_validate、Istat、质量门          无法证明模型可信或统计收敛
物理示意（不是流程图）：


装配前：     X_i = X_i0 + δ_i^SMS           -> 形成两侧结合面的初始几何差
接触中：     0 <= λ_n ⟂ g = q + W λ_n >= 0 -> 求得阶段接触力、间隙、压缩
预测端：     Δy_KCP = 几何直接项 + 接触附加项 + 工艺过程项
统计端：     对每个 ξ 样本重复完整计算链，而不是只对一次 KCP 加噪声


总体通过判据：只要八类输入包存在，SMS 后验能构造 g0，W_total 半正定且 LCP 可解，阶段状态能按参
考态传递，贡献台账无重复源，KCP 能被独立验证，那么这套数学模型就可以端到端走通。

2 环节二：测量状态补偿，先得到可更新 SMS 的参考态 KCM
柔性薄壁件在测量台上已经受重力、支承、检具和夹持影响。若把受载测量点直接当作制造形貌，后续阶段接
触求解会把同一变形再算一遍。因此，必须先把原始测量拆分为制造形貌、刚体位姿、测量边界变形、局部接
触压缩和偏置。
    m_raw^(m) = H_δ N α + H_pose e_pose^(m) + H_u u_struct^(m) + H_c w_local^(m) + b_m + ε_m

    m_ref = m_raw - H_pose ê_pose - H_u û_struct - H_c ŵ_local - b̂ _m

    R_ref = R_raw + J_comp Σ_comp J_comp^T + J_T Σ_T J_T^T
    简单示意：测量值不是 SMS 本身


    m_raw   =   制造形貌 + 位姿误差 + 测量支承/重力变形                     +   局部接触压缩      +   仪器偏置
    m_ref   =   m_raw    - 可辨识的非制造项
    SMS     =   用 m_ref 更新，而不是用 m_raw 更新

3 环节三：KCM 更新 SMS，得到装配前制造形貌后验
SMS 只表示零件在装配前参考状态下的制造态形貌。它不包含定位变形、夹持变形、连接压缩和释放回弹。
    X_i = X_i^0 + δ_i^SMS,       δ_i^SMS = N_i α_i

    m_KCM = H_m N α + b_m + ε_m,        ε_m ~ N(0, R_m)

    α_hat = argmin_α { ||m_ref - H_m N α - b_m||^2_{R_ref^{-1}} + λ ||L(α-α0)||_2^2 }

    Σ_α,post ≈ (N^T H_m^T R_ref^{-1} H_m N + λ L^T L)^{-1}
    简单示意：低维形貌基


    零件表面偏差 δ_SMS(x,y)
       ≈ α1 · 整体弯曲模态
        + α2 · 扭转/斜率模态
        + α3 · 边缘翘曲模态
        + ...

16 最终结论：这套操作流程可以走通的关键原因
    几何链闭合：KCM 经过测量状态补偿后更新 SMS，SMS 通过 G 映射成 g0。
    力学链闭合：离线 W_struct 与局部 Cn 形成 W_total，阶段 LCP 求得接触力、间隙、压缩和模式。
    状态链闭合：LOCATE、CLAMP、JOIN、RELEASE 保存绝对后验状态和阶段增量，按传递规则进入下一阶段。
    预测链闭合：界面状态经输出导向凝聚为 Δγ_c，再由 JSS/J-T 传递到 KCP。
    统计链闭合：每个 Monte Carlo 样本都重复完整快速链，而不是对最终 KCP 加噪声。
    验证链闭合：D_identify、D_calibrate、D_validate 分离，验证失败触发新版本而非同集调参。
    防重复链闭合：每个贡献都有 source_id、reference_state_id 和 increment_definition_id，同一变形源只能消费
     一次。
因此，在硕士论文中可把该流程写成“输入组织与测量补偿 - SMS 更新 - 初始间隙与结构凝聚 - 多阶段界面互
补 - 过程实测状态/参数更新 - 输出导向凝聚 - KCP 快速预测 - Monte Carlo 与独立验证”的可执行数学模
型，而不是停留在概念流程。
