# 阶段实测后验更新与状态回代：实现约束

> 文档性质：阶段实测后验更新的软件实现合同  
> 适用范围：已完成的 `topology_step` 确定性多轮装配执行器之上的增量能力  
> 数据真实性：合成测量只用于数值一致性验证，不允许工程精度声明

## 1. 实现边界

1. 本轮只更新数据包定义的低维阶段状态 `eta_s`，不更新慢参数。
2. 不修改装配前 SMS，不重新估计或写回 SMS。
3. 不修改 `Cn`、`Ct`、`mu`、`beta_r`、连接刚度或其他参数快照。
4. 不实现阶段实测参数辨识、非线性状态-参数联合估计、EKF、UKF、粒子滤波或多次高斯-牛顿迭代。
5. 不实现虚拟 SMS 滚动预测、Monte Carlo 后验传播、在线 FE/Schur 重构或完整摩擦 NCP。
6. 低维 `eta_s` 及其协方差只表示数据包定义的更新状态，不冒充全阶 FE 位移或全阶状态协方差。
7. 合成测量和合成算子只证明更新、重求和传递链数值自洽；`engineering_claim_allowed=false`。

## 2. 测量用途与权限

1. `CALIBRATE` 测量允许进入本轮阶段状态更新。
2. `UPDATE` 不是 V2.5 基础规范的原始 `data_role` 枚举；仅允许 schema adapter 将其显式规范化为 `CALIBRATE`，并保留原始角色追溯。
3. `VALIDATE` 只允许计算评价残差，不得触发更新。
4. `IDENTIFY` 只用于离线参数识别，不进入本轮状态更新。
5. 缺少 `data_role` 不得默认获得更新权限。
6. `update_target` 必须指向允许的阶段状态分量。指向 SMS、`Cn`、`Ct`、`mu`、`beta_r`、连接刚度或其他参数的测量必须阻断或明确标记 `SKIPPED_NOT_ALLOWED`。
7. `quality_flag`、单位、坐标系和参考状态必须通过检查；不存在明确转换时不得隐式换算。
8. 运行时覆盖只能替换匹配 checkpoint 和 measurement ID 的值与不确定度，不能修改用途、目标或治理字段，也不得写回数据包。
9. `sample_id`、measurement set/ID、stage/checkpoint、`vector_source`、object/interface/global index 必须与运行时状态和公共 `VectorLayout` 一致；第一版只允许 `RUNTIME_STAGE_STATE`。
10. `VALIDATE` 是 evaluation-only，必须报告 prior/post 物理残差但不得进入 H/R/K；`IDENTIFY` 记录为 skipped。仅含二者的 checkpoint 不更新、不重求 LCP，也不生成 rollback。

## 3. checkpoint 与双状态

1. 每个有效 `measurement_checkpoint_id` 必须唯一对应一个 `topology_step`。
2. checkpoint 必须显式给出 `source_topology_step_id`，不得从编号或字符串猜测机械源步骤。
3. 预测状态与后验状态必须同时保存，不得用后验状态覆盖或删除预测状态。
4. 成功状态链为：上一有效状态 -> 当前 PREDICTED -> 当前 POSTERIOR -> 下一 PREDICTED。
5. 后续步骤只继承成功接受的后验状态；更新失败时保留预测状态为有效状态。
6. 后验状态继承当前子装配体、活动接口、活动连接、边界、载荷、JOIN 锁定历史、RELEASE 历史和参考状态；接触模式只作为暖启动信息。

## 4. 数学更新

本轮采用一次确定性线性高斯更新：

```text
z_meas = z_pred + H delta_eta + v,     v ~ N(0, R)
r      = z_meas - z_pred
S      = H P_prior H^T + R
K      = P_prior H^T S^-1
eta_post = eta_prior + K r
```

不得显式计算矩阵逆。实现使用 Cholesky 或 `numpy.linalg.solve`；只有配置明确允许并记录质量警告时才允许正则化或伪逆。

后验协方差必须使用 Joseph 形式：

```text
P_post = (I - K H) P_prior (I - K H)^T + K R K^T
```

下一步骤的低维状态和协方差传递为：

```text
eta_k^- = F_k eta_parent^+
P_k^-   = F_k P_parent^+ F_k^T + Q_k
```

缺少显式 `F/Q` 时使用明确记录的 `F=I, Q=0` 近似，不得描述为未知全阶协方差传播。

## 5. q 映射与物理重求

1. 状态修正通过数据包显式矩阵进入自由间隙：

   ```text
   当前 checkpoint:
   q_post = q_source_effective + G_q (eta_post - eta_prior)

   后续新 topology_step:
   q_effective = q_operator_base + G_q eta_current
   ```

2. 必须分别记录 `q_operator_base`、`q_source_effective`、`eta_increment`、`q_update_increment`、`q_effective_after_update` 与 `q_base_semantics`，不得混用原始算子 q 和已含状态修正的有效 q。
3. `G_q` 行布局必须对应公共接触 `VectorLayout`，列布局必须对应 `update_state_layout_id`。
4. 后验已存在但当前或后续受影响算子缺少 `G_q` 时必须阻断，不得静默忽略。
5. q 改变必须产生 `ReSolveRequirement=RESOLVE_LCP`，并使用原有

   ```text
   W_total = W_struct + Cn
   ```

   对全部活动接口只执行一次统一全局 LCP。
6. 必须使用 `np.ix_` 提取活动子矩阵并保留 `W_struct` 的跨接口非对角块。
7. 后验重求单独记录调用次数，不伪装成新的 `topology_step`。
8. 本轮不声明支持 `REBUILD_W`、`REBUILD_IRED` 或 `HIGH_FIDELITY`。

## 6. 接受、质量门与回滚

1. prior、post-LCP 和 VALIDATE 必须使用同一个公共 observation extractor；第一版只支持 `GAP_G`、`LAMBDA_N`、`PRESSURE_P_N`、`LOCAL_COMPRESSION_W_N`。
2. 必须分别保存 `z_predicted_prior_physical`、`z_predicted_posterior_linearized`、`z_predicted_posterior_physical` 及其三类残差；线性后验只用于诊断线性化误差。
3. 更新前检查 checkpoint 外键、步骤顺序、测量集、用途权限、质量、参考状态、坐标系、单位、观测顺序、矩阵 shape/layout、协方差对称性/半正定性和后续映射完整性。
4. 声明完整 R block 后，缺失 key、shape/layout 错误、非有限、非对称或非正定均为 blocking FAIL。只有完全未声明 block 且配置显式允许时，才可使用 `standard_uncertainty^2` 对角回退，并报告协方差来源。
5. 更新后从实际全局 LCP 的 lambda/gap/pressure/local compression 重新提取物理观测，使用 Cholesky/solve 计算 `r^T R^-1 r`；正式接受依据必须是 post-LCP 加权物理残差、配置阈值、单项恶化、LCP、NIS、PSD 与状态链质量门。
6. 更新后还要检查有限性、Joseph 协方差对称性/半正定性、协方差下限、活动接口、跨接口块、状态父链、参数冻结和 SMS 冻结。
7. 参数/SMS 冻结快照必须在任何数值处理前取得，并在 LCP、观测提取和全部质量门之后复核；覆盖 SMS、材料/参数表、Cn/Ct、mu/beta、连接刚度、W_struct 与 MatrixManifest。
8. 任一阻断条件失败时生成 `UpdateRollbackRecord`，标记 `POSTERIOR_REJECTED_ROLLBACK`，并保留预测状态为有效状态。
9. 回滚不得覆盖上一有效后验状态，也不得把失败结果静默标为 PASS。

## 7. 规范冲突与适配解释

1. V2.5 完整说明书的 `data_role` 枚举为 `IDENTIFY/CALIBRATE/VALIDATE/MONITOR/EXCLUDE`；任务要求兼容 `UPDATE`。本实现保留规范枚举为基础，只在适配层显式记录 `UPDATE -> CALIBRATE`。
2. V2.5 `StagePosteriorPackage` 可包含参数快照；本轮按更窄任务合同冻结所有参数，只生成低维阶段状态后验和参数冻结证据。
3. 旧包的过程记录可能来自 `I_stage/process_record.csv`；本轮优先读取 `I_meas/measurement_record.csv`，兼容 `I_meas/process_record.csv` 和既有适配表，但不依靠 `stage_id` 模糊关联 checkpoint。
4. 多零件条款以同步修订稿为增量覆盖：公共 `VectorLayout`、完整交叉块和统一全局 LCP 不得退化。
