# SMS软件升级参考资料索引

## 使用方式

开始修改前先阅读本索引，再按照任务范围阅读对应资料。`reference/extracted_text/` 是便于搜索的机械提取文本，PDF是最终核对依据。

## 基础规范

### 0. `reference/00_data_structure_v25_full.pdf`

原名：《数据结构说明书_V2.5_V2.2风格正式版》

这是完整的数据结构基础规范，用于确定全部对象体系、CSV字段、主键、外键、矩阵、量纲、状态传递、数据治理、预测、验证和版本规则。任何数据结构修改都应先查本文件。

## 多零件增量覆盖

### 1. `reference/01_data_structure_v25_multipart.pdf`

原名：《数学模型数据结构说明书_V2.5_多零件串并联同步修订稿》

本文件不是完整说明书。它替换和补充完整说明书第2、3、6、7、8、11、14章及附录A中与多零件装配有关的条款；未涉及对象继续遵循完整说明书。

主要用于核对：

- 多零件串联、并联和闭环拓扑；
- Part、Interface、Joint、Subassembly及TopologyStep；
- 多ContactDomain公共VectorLayout；
- 全局接触向量和矩阵分块；
- `W_struct`接口交叉柔度块；
- 多接口统一LCP；
- LOCATE、CLAMP、JOIN、RELEASE状态传递；
- 连接锁定历史；
- 多路径贡献唯一键和防重复计算。

## 解释优先级

出现不一致时，采用：

1. 完整说明书定义通用对象、字段和治理规则；
2. 修订稿生效范围内的多零件条款覆盖完整说明书对应条款；
3. 四零件数据包用于校验实际外键、布局和矩阵维度；
4. 最新软件通过适配层维持新旧数据兼容。

四零件数据只能作为最小集成基准，不能成为软件的固定规模。合成矩阵和合成结果不得用于真实工程精度声明。
